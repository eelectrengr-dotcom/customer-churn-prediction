Customer Churn Prediction System

This project is a machine learning application that predicts whether a customer will leave a company or not. The model is built using XGBoost and deployed using Streamlit.

----------------------------------------

Features

- Manual customer churn prediction
- Bulk prediction using CSV file upload
- Simple and user-friendly interface
- Fast and interactive Streamlit dashboard

----------------------------------------

Technologies Used

- Python
- XGBoost
- Streamlit
- Pandas
- NumPy
- Scikit-learn
- Matplotlib

----------------------------------------

Project Files

- app.py (Streamlit application)
- train_model.py (model training script)
- requirements.txt (dependencies)
- WA_Fn-UseC_-Telco-Customer-Churn.csv (dataset)

----------------------------------------

How to Run

Step 1:
pip install -r requirements.txt

Step 2:
python train_model.py

Step 3:
streamlit run app.py

----------------------------------------

Dataset

Telco Customer Churn dataset is used for training.
